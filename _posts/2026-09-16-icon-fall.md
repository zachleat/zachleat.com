I’ve been doing some spring/fall cleaning and found an unpublished follow-up component to [`<snow-fall>`](/web/snow-fall/) (a web component to “snow” on your website — which also happens to work with emoji too). Originally it was created as an easter egg for [Blog Awesome](https://blog.fontawesome.com/) (click on the Font Awesome flag in the very bottom of the footer) but others have wanted to use it for more things!

Presenting: `<icon-fall>`:

* [Demo](https://zachleat.github.io/icon-fall/demo.html)
* [Source code on GitHub](https://github.com/zachleat/icon-fall)

It’s in use on this page (if you are on my web site and not in a feed reader). You can also install it with `npm install @zachleat/icon-fall`.

It has options for `count` (attribute, number of icons) and a comma separated list of colors (via `--icon-fall-colors` custom property).

<script type="module" src="/static/icon-fall.js"></script>
<is-land on:media="(prefers-reduced-motion: no-preference)">
	<icon-fall count="20" style="--icon-fall-colors: #548cd8,#f36945,#00a776">
		{% icon "fab:font-awesome" %}
		{% icon "fab:web-awesome" %}
		{% icon "fab:build-awesome" %}
	</icon-fall>
</is-land>
